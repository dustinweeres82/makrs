# Hertical Sans 800 — font files go here

Place the following files in this directory:

- `hertical-sans-800.woff2`
- `hertical-sans-800.woff`

These are self-hosted (paid licence, provided by Kandis). Do NOT commit them to a public repo.
Add both filenames to .gitignore if the repo is public.

The @font-face declaration in `app/globals.css` is already wired up — just drop the files here.
